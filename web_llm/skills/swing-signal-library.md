# 波段訊號庫

## 何時使用
- 「給我一個能避開摩擦的訊號」「波段策略哪個好」「效率比怎麼算」。
- 對象是**低頻、可留倉**的訊號；日內高頻請改用 `orb-intraday-analyzer`（且已證實會賠）。

## 首選建議
- **以「保住本金」為準 → 高效波段 30m**：回落僅 ≈33% 本金、恢復 4.56。
- DMI 120m 雖 7/7 年皆賺，但回落 ≈89% 本金 → 1 口 7 萬本金幾乎爆倉，**不建議當核心**。

## 效率比 (ER) 定義
ER = N 根淨位移 ÷ N 根總路徑長。接近 ±1 = 順暢趨勢；接近 0 = 盤整。
進場：ER 上穿 +0.5 做多 / 下穿 −0.5 做空（過 AntiFrequency 濾網）；出場：ER 跌破/突破 0 順勢出。

## 必要警語（每次回答附上）
1. 這些訊號**必須留倉**才有邊際，與「絕不留倉、單日 −2890」的日內規則衝突。
2. 仍是訊號層測試；上線前要加移動停損、單筆風險上限、依本金的口數控制（見 `exit-module-designer` / `filter-module-designer`）。
3. 勝率僅 31–43%，連輸是常態，心理難熬。
