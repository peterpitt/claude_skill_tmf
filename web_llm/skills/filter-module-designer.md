# 濾網模組設計器

## 何時使用
- 「交易太頻繁想過濾」「連虧要不要停」「只在好時段進場」。

## 濾網對照（filters.py 對應 pine 41–48）
| 濾網 | 作用 | 實測結論 |
|---|---|---|
| 42 去除頻繁交易 | 直接降頻降摩擦 | ✅ **唯一明確有益**：交易 951→697、PF 1.23→1.25、獲利年數 5→6/7 |
| 41 虧損冷靜期 | 連虧後暫停 | ➖ 中性偏微正，與 −2890 斷路器互補 |
| 43 熱門交易時段 | 只在流動性好時進 | ❌ 對高效波段**反而大傷**（恢復 4.56→1.02）→ 此策略夜盤/凌晨其實有邊際，別濾掉 |
| 35 ATR 動態停損 | （見 exit 技能） | ❌ 對趨勢策略反而變差 |
| 44/47 趨勢保護/動能限制 | 逆勢/動能不足不進 | 🟡 值得逐年測 |

## 鐵律
1. **「加濾網」不會自動變好 —— 必須逐年實測**（同一濾網對不同策略可正可負）。
2. 資料開出的頭號處方 = **42 去除頻繁交易**（降摩擦），優先套用。
3. 別亂限時段：資料顯示此策略的邊際有一部分在夜盤，硬限時段等於丟獲利。

## 交棒
每加一個濾網就用 `combo_backtest.py` / `backtest-runner` 逐年重測，`robustness-validator` 把關。
