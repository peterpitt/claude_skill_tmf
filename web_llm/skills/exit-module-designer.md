# 出場模組設計器

## 何時使用
- 「幫我加移動停損」「ATR 停損怎麼設」「這波段策略要怎麼出場」。

## 出場模組對照（pine 31–40）
| 型態 | 用途 | 對 TMF 建議 |
|---|---|---|
| 固定點數 (31) | 基本停損停利 | ✅ 系統已有，可對照參數 |
| 百分比 (32) | 換算成點數即用 | ✅ |
| 反彈拉回點數/百分比 (33/34) | **移動停損鎖利** | ✅ ORB 已部分實作 |
| ATR 動態停損 (35) | 依波動調整 | ✅ 比固定點數穩健，**但見下方警告** |
| 動態時間 (36) | 持有 N 根未獲利就出 | ✅ 控曝險時間 |
| 不創高破低 (38) | 動能衰竭即走 | ✅ |
| 萬用出場 (40) | 整合多種 | ✅ **最佳移植範本** |

## 關鍵實測教訓（combo_backtest.py，勿違反）
- 對**趨勢/效率比策略硬加 ATR 固定停損 → 反而變差**（恢復 4.56→0.89）：硬停損打斷「跌破 0 才出場」的順勢邏輯，反覆被掃。
- 結論：**趨勢策略不該硬加固定停損**；波段用「訊號反轉出場 + 依本金的口數控制」優先，移動停損只鎖大幅獲利。

## 交棒
設計完成後用 `backtest-runner` 逐年驗證，再用 `robustness-validator` 確認非過度配適。
