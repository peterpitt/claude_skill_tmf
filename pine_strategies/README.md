## TMF 自動交易適用性：總覽

判斷標準＝能否對接我們現有系統（**TXF 訊號 → TMF 市價單**、早/夜盤、每盤 4 次、單日 −2890），
以及**對照你真實資料的鐵證**：*5 分日內、高頻 + 微型合約 + 7 萬本金，光摩擦成本一年就吃掉整副本金，
任何高頻日內訊號都先天必敗*。因此「適用」不只看能不能接，更看**能不能避開摩擦陷阱**。

| 圖示 | 意義 |
|---|---|
| 🟢 | 直接可用 / 值得用 `txf_kbars.csv` 逐年回測（多為可拉高週期的波段訊號，或能降低摩擦的元件） |
| 🟡 | 可移植，但需調整、重實作為 Python，或邊際存疑（含我們已測過會賠的日內型） |
| 🔴 | 不適用本系統（非策略的語法教學，或需第二檔報價的跨商品價差） |

## 結論與建議（誠實版）

**1. 真正值得用 `txf_kbars.csv` 逐年回測的「訊號」候選（優先序）：**
- 🥇 **51 高效波段**、**50 多空對翻**、**11 均線多空排列**、**10 MACD**、**14 DMI** —— 都是**低頻波段**型，
  最可能避開「高頻摩擦必敗」的陷阱。建議在 **15m / 30m / 60m / 日線** 各跑一次逐年驗證。
- ⚠️ **21 ORB、20 箱型、52 日內、13 CDP** —— 都是日內高頻型，我們**已用你的真實資料證明會逐年虧損**，
  除非大幅降頻，否則不建議。

**2. 立刻能讓我們現有 TMF 系統變更好的「元件」（不必等回測就值得移植）：**
- **42 去除頻繁交易 + 43 熱門交易時段 + 41 虧損冷靜期 + 47 動能限制** → 直接降低交易次數與摩擦，
  正是你資料分析開出的處方。
- **35 ATR 動態停損 + 40 萬用出場 + 33/34 移動停損** → 把我們現在的固定點數停損升級成隨波動調整。

**3. 不適用（需改架構或非策略）：** 01–07（語法教學）、23/24/54（價差套利，需第二檔報價）。

> 一句話：**這份課程的價值不在「指標進場」（那些多是會被摩擦磨死的高頻訊號），
> 而在「出場 D + 濾網 E」這些降摩擦、控曝險的模組** —— 那才是把 7 萬本金保住的關鍵。
