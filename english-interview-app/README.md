# 🎯 30 天 Google 面試英語衝刺 · English Interview Sprint

一個由 AI 發想、專為「**聽得懂英文、但開不了口跟外國人流利溝通**」的人打造的中英雙語學習 Web App。
跟著 30 天的結構化課程，每天 20–30 分鐘，從最基本的問候開口，一路練到能完整參加 Google 這類外商的英文工作面試。

## ✨ 特色

- **30 天結構化課程**：四週循序漸進
  - Week 1：打底 — 開口說 + 自我介紹
  - Week 2：職場英語 + STAR 行為面試法
  - Week 3：Google 技術 / 情境面試溝通
  - Week 4：完整模擬面試 + 流利度衝刺
- **中英雙語對照**：每天含重點字彙（附 KK 音標、例句）、實用句型、情境對話、面試題演練與參考回答、當日挑戰任務。
- **🔊 發音朗讀**：所有英文句子一鍵朗讀（Web Speech API），跟著唸準發音與語調。
- **🎙 口說練習與語音辨識**：對著麥克風跟讀，系統把你說的英文轉成文字並計算相似度，立即知道哪裡沒說清楚。
- **🃏 單字卡複習**：從學過的天數隨機抽字翻卡自測。
- **🎤 Google 面試模擬器**：隨機抽面試題（行為 / 技術 / 動機三大題型），語音作答即時轉文字，搭配自評清單。
- **📊 進度追蹤**：完成天數、連續學習、進度環，全部自動存在瀏覽器（localStorage），離線可用。

## 🚀 使用方式

這是一個純前端 App，不需要伺服器或安裝任何東西：

```bash
# 方法一：直接用瀏覽器打開
open english-interview-app/index.html      # macOS
# 或在檔案總管雙擊 index.html

# 方法二（建議，語音功能更穩定）：起一個本機伺服器
cd english-interview-app
python3 -m http.server 8000
# 然後瀏覽器打開 http://localhost:8000
```

> 💡 **建議使用 Chrome 或 Edge**，以完整支援語音朗讀與語音辨識功能。

## 📁 檔案結構

```
english-interview-app/
├── index.html      # 主頁面與版面
├── styles.css      # 樣式（深色主題、RWD 響應式）
├── curriculum.js   # 30 天課程資料 + 面試題庫（易於擴充/修改）
└── app.js          # 互動邏輯：進度、發音、語音辨識、單字卡、模擬器
```

## 🛠 如何客製化課程內容

所有課程內容都集中在 `curriculum.js` 的 `CURRICULUM` 陣列，每天一個物件：

```js
{
  day: 1, week: 1,
  titleZh: "中文標題", titleEn: "English Title",
  goalZh: "今日學習目標",
  vocab:     [{ en, zh, ipa, ex }],   // 字彙
  patterns:  [{ en, zh }],            // 句型
  dialogue:  [{ role, en, zh }],      // 對話
  interview: [{ q, tip, sample }],    // 面試題 + 技巧 + 範例
  task: "今日挑戰任務",
}
```

想改成準備別家公司（Meta、Amazon…）或別種職缺的面試，只要編輯這個檔案即可，無需動到程式邏輯。

## 📖 30 天課程總覽

| 週次 | 天數 | 主題重點 |
|------|------|----------|
| Week 1 | Day 1–7 | 破冰開口、自我介紹、數字時間、描述工作、談過去/未來動機、複習 |
| Week 2 | Day 8–14 | STAR 法則、團隊合作、談失敗、領導力、會議英語、非同步溝通、故事庫 |
| Week 3 | Day 15–21 | 出聲思考、澄清問題、系統設計用語、卡住怎麼說、反問問題、聽力追問、技術模擬 |
| Week 4 | Day 22–30 | 完整開場、行為連環題、技術連環題、薪資收尾、流利度、發音、兩段完整模擬、驗收日 |
