# 🎬 ShortReel Studio — 一站式短影音變現平台

把「大神同款」的 9 個 AI 工具（ChatGPT、coze、Hailuo、ElevenLabs、Canva、Gemini、manus、NotebookLM、HeyGen）串成一條龍的短影音生產與變現工作台。

> 靈感來自「用上述工具打造一站式短影音變現工作平台」的作法 —— 這裡把那套**工作流具體化成一個可操作的平台**：從選題到收益，每一步都有對應工具與 Prompt，並追蹤成本與投報率。

## ✨ 功能

| 模組 | 說明 |
|------|------|
| 📊 **儀表板** | 專案數、製作中/已發布、累積收益、**本月 ROI**（收益 vs 全套工具月費 $389.69）與流水線分布 |
| 🗂️ **製作流水線** | 7 階段看板，**拖曳卡片**即可推進：選題 → 腳本 → 配音 → 影片 → 數位人 → 封面 → 發布 |
| ✨ **Prompt 工作室** | 每個階段一鍵取得專用提示詞，複製後貼進對應 AI 工具 |
| 🧰 **AI 工具箱** | 9 個工具卡（角色分工、月費、直達連結） |
| 💰 **變現追蹤** | 總收益、成本、淨利，各發布平台收益彙總 |

## 🔗 工具 → 流程對應

```
💡 選題靈感   ChatGPT · Gemini · NotebookLM
✍️ 腳本撰寫   ChatGPT · Gemini
🎙️ AI 配音    ElevenLabs
🎬 影片生成   Hailuo 海螺
🧑‍💼 數位人口播 HeyGen
🎨 封面設計   Canva
🚀 發布變現   coze · manus
```

全套月費：**$389.69 美金/月**（與參考圖一致）。

## 🚀 使用方式

純前端、零依賴、免安裝，直接開檔即可：

```bash
# 方法一：直接雙擊 index.html

# 方法二：本機起一個簡單伺服器
cd short-video-platform
python3 -m http.server 8080
# 瀏覽器打開 http://localhost:8080
```

- 資料以 **localStorage** 存在瀏覽器本機，重開仍在。
- 側欄「↺ 還原示範資料」可清空並回到示範專案。
