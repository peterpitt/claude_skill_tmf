# 交易日誌格式與評分細則

## 成交紀錄 CSV 欄位（建議，讓「跟新」很簡單）

日誌的價值來自持續累積。建議他維護一個 append-only 的 `trades.csv`，每天收盤後補上當天幾列，
之後每週直接把整份丟進來就能彙整。欄位（缺的儘量補，`理由`與`情緒`最關鍵、不能省）：

| 欄位 | 範例 | 說明 |
|---|---|---|
| `date` | 2026-07-28 | 交易日 |
| `time` | 09:52 | 進場時間 |
| `session` | 早 / 夜 | 早盤或夜盤（判斷 4 次上限與強平規則用） |
| `mode` | 日內 / 波段 | 日內(orb/ma_fvd) 或 波段(efficiency)——**判斷留倉是否違規的關鍵** |
| `side` | 多 / 空 | 方向 |
| `qty` | 1 | 口數 |
| `entry` | 23150 | 進場價 |
| `exit` | 23108 | 出場價 |
| `pnl_twd` | -420 | 損益（TMF：點數×10×口數 − 成本） |
| `rule` | 效率比>0.5 / 無 | 這筆依據哪條訊號規則；「無」= 憑感覺（危險訊號） |
| `emotion` | FOMO | 當下心情：FOMO / 報復 / 猶豫 / 平穩 |
| `note` | 訊號09:45就出，我拖到09:52才追 | 一句當下想法 |

> 沒有 `rule` 和 `emotion` 這兩欄，就無法評斷決策品質。若他的紀錄缺這兩欄，先請他補，
> 或在復盤時逐筆問他「這筆進場的依據是什麼？當下什麼心情？」

## 每日輸出範本

```
📓 交易日誌 — 2026-07-28（早盤）
逐筆：
  #1 09:12 多 1 口 | 依據：效率比>0.5 ✅是 | 情緒：紀律良好
     決策：教科書級進場，訊號到位才動手。結果虧 −180 是機率成本，這筆做得對。
  #2 09:52 多 1 口 | 依據：無（追高）❌否 | 情緒：FOMO
     決策：訊號 09:45 就出，你拖到 09:52 才追，慢了 7 分鐘。⚠ 這筆賺了 +260，
     但它是壞流程——別讓「追高也會賺」騙了你，長期這種單會還回去。
當日總結：2 筆中 1 筆守紀律。今天賺錢，但賺在僥倖的那筆，紀律其實不及格。
```

## 每週輸出範本

```
📊 本週復盤（7/28–8/1）
紀律分數：72 / 100（11 筆中 8 筆符合既定規則；不計損益）
最常犯的錯：追高進場——7/28、7/29 各一次在訊號已過後才追，都是 FOMO。
本週唯一要改：訊號出現後 60 秒內沒進場，就當這筆不存在，不追。
教練話：這週你在「等訊號」上做得比上週好（猶豫沒進的次數少了），
        現在敵人只剩一個：追高。專心把上面那條做到，下週我們只看這件事。
```

## 紀律分數算法

核心：**符合既定規則的比例**，與賺賠無關。

1. 基準 = 符合規則的筆數 ÷ 總筆數 × 100。
   （`rule` 非「無」、且未違反出手上限/留倉/斷路器 → 算「符合」。）
2. **重罰項**（每次扣 10–20，可扣到 0）——這些是會爆倉等級的行為：
   - 手動繞過 −2,890 斷路器硬凹
   - 日內模式抱單過夜（違反絕不留倉）
   - 報復性交易（剛虧完立刻加倍下單）
3. **輕罰項**（每次扣 3–5）：追高慢進（判「半」）、超出當盤 4 次上限的第 5 筆起。
4. 分數旁一定註明算法與被扣分的具體筆，讓他知道下週往哪裡修。

> 分數是給他自己看進步的儀表板，不是評價他這個人。連續幾週看趨勢比單週絕對值更有意義。

## 復盤時常見、要主動抓的致命模式

- **賺錢日的壞決策**：最容易被放過，卻最毒。主動在賺錢的日子找有沒有僥倖單。
- **憑感覺的日內單**：`rule=無` + `mode=日內`。呼應 D1 結論——這是他已證明沒邊際的系統，
  手癢做只會被摩擦成本磨死。點名它。
- **凹單**：虧損單不停損、或斷路器後硬加碼。這是本金殺手，最高優先級點名。
- **時段錯配**：把波段訊號當日內做（訊號到就想當天平掉），或反過來。對照 `mode` 欄抓。
