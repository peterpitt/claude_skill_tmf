TMF 台指期 自動交易系統

最終配置：微型台指 TMF · 固定 1 口 · 高效波段(效率比) 30 分 K · 留倉波段。本頁教你從下載到實際下單。

⚠️ 先讀這段（攸關你的資金）
  • 期貨是槓桿商品，可能虧損超過本金。本系統僅供研究與自負風險使用，作者不對任何虧損負責。
  • 系統預設 DRY_RUN（只算訊號、不送單），不會自己動用真錢。要動真錢必須手動解開三道安全閘。
  • 這套策略會留倉（隔夜）。它的邊際來自波段，與「絕不留倉、單日 −2890」互斥；資金保護改由 1 口固定部位 + 策略自身出場 負責。
  • 真實資料逐年回測：恢復係數約 2.9、6/7 年正報酬，但最大回落≈本金 30%、勝率僅約 40%（連虧是常態）。心理與資金都要能撐住。

一、這系統在做什麼

  • 訊號來源：大台 TXF 即時報價 → 自行合成 30 分 K 線。
  • 進場：用 Kaufman 效率比 (ER) 判斷趨勢是否「順暢」。ER 由下穿越 +0.5 做多、由上穿越 −0.5 做空（並過「去除頻繁交易」濾網）。
  • 出場：ER 跌破／突破 0 即順勢出場（刻意不加硬停損——回測證實硬停損會打斷順勢、反而變差）。
  • 下單：對 當月 TMF（NT$10/點） 送出範圍市價、固定 1 口；多空可反手；會留倉。
  • 風控：獨立執行緒監看損益＋部位簿即時對帳；本配置停用單日斷路器（波段不適用），靠 1 口固定部位控管。

二、開始前你需要準備（在永豐金證券辦）

1
開立期貨帳戶並入金（跑 1 口 TMF 保證金不高，但建議帳上留足夠緩衝）。
2
申請 Shioaji API 權限，取得 API Key 與 Secret Key。
3

六、執行

先做設定自我檢查（不連線、不下單）

python main.py --check

會印出契約＝TMF、每點 10 元、策略＝高效波段、交易型態＝swing 等，確認無誤再往下。

直接執行

python main.py

建議：用 tmux 常駐（斷線也能跑、crash 自動重啟）

chmod +x run.sh
./run.sh          # 啟動（背景 tmux session 名為 tmf）
./run.sh attach   # 連入看即時 log（離開按 Ctrl-b 再按 d）
./run.sh stop     # 停止

所有交易與風控都會寫進 logs/trade_YYYYMMDD.log，事後可完整稽核。

九、常見問題

它會自己停損嗎？

不設硬停損；出場由「效率比跌破 0」觸發，或多空反手。下檔風險靠固定 1 口限制。若你無法接受沒有硬停損，這套策略可能不適合你。

會留倉嗎？我原本要當沖。

會留倉。這正是它能擺脫日內摩擦的原因。若你堅持絕不留倉，回測顯示日內版只能約略損益兩平——那條路我們已驗證走不通。

為什麼斷路器設 0（停用）？

單日 −2890 是日內風控；波段留倉的正常隔夜波動就常超過它，硬套會不斷砍掉好部位、毀掉策略邊際。所以改用 1 口固定部位控管風險。

程式關掉後，手上的單怎麼辦？

正常用 Ctrl-C 或 ./run.sh stop 結束時，會嘗試平掉部位再登出。但網路／主機異常時不保證，請務必另在永豐 App 設定即時損益提醒並能手動平倉。

最後叮嚀：先 DRY_RUN → 再模擬一週 → 真錢只用 1 口並盯盤。任何「保證獲利」的說法都不要信，包括這套系統——它只是一個有逐年邊際、但仍會大幅回落的工具，不是印鈔機。保住本金，永遠比多賺一筆重要。
